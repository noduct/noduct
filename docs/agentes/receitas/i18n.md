# Adicionar texto i18n

## Pré-condições

Defina contexto, parâmetros e os três idiomas antes de editar a UI.

## Arquivos afetados

Mensagens de hub ou pacote, componente, teste de i18n.

## Referência canônica

[mensagens do hub](../../../src/i18n/messages.ts) e [shell](../../../packages/design-system/src/shell/messages.ts).

## Passos e validação

1. Leia [AGENTS.md](../../../AGENTS.md) e [guardrails](../../guardrails.md).
2. Faça um plano curto e implemente a menor mudança verificável.
3. Execute `npm run check`; `npm run verify`.
4. Registre o resultado e a justificativa no PR.

## Erros comuns

Frase fixa no script cliente, `aria-live` omitido, erro de domínio com texto, nome de arquivo sem tradução.

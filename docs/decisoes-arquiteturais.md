# Decisões arquiteturais

## Registro

- Astro estático: entrega HTML útil, baixo JavaScript e compatibilidade com Pages.
- Sem React: busca e tema não justificam runtime adicional.
- Manifesto TypeScript: uma fonte de verdade com validação Zod no build/CI.
- Repositórios independentes: isola deploy, dependências e falhas de cada ferramenta.
- Roadmap visível sem links: transparência sem páginas vazias ou falsas.
- Patrocínio manual: evita backend e falsa confirmação de pagamento.
- Modo comercial prelaunch: preserva conformidade enquanto a hospedagem é avaliada.

Detalhes formais estão em `docs/adr/0001-static-independent-tools.md`.

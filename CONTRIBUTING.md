# Como contribuir

Use Node.js compatível com `package.json`, crie uma branch curta e execute `npm run validate` antes de abrir um pull request. Interface pública, metadados e código ficam em inglês; documentação técnica fica em PT-BR.

Novas ferramentas precisam ser implementadas em repositório próprio antes de receber status `published` no catálogo. Não inclua dados pessoais, segredos, métricas inventadas ou alegações de privacidade que não correspondam ao processamento real.

Mudanças visuais devem reutilizar os tokens existentes. Mudanças arquiteturais relevantes devem atualizar a documentação e, quando necessário, adicionar um ADR em `docs/adr/`.
